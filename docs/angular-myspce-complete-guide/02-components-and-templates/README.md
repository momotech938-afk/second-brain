# Module 02 — Components, Templates and Data Binding

Components are everything you see in Myspce: the sidebar, every card, every page. This module teaches how to write them, bind data into them, and organise them.

Back to [README](../README.md) · Previous: [Module 01](../01-angular-fundamentals/README.md) · Next: [Module 03](../03-template-control-flow/README.md)

## Self-assessment checklist

- [ ] I can write a standalone component with an external template and styles, and use it in a parent.
- [ ] I can explain view encapsulation and when to use `:host`.
- [ ] I can bind text, properties, events and two-way values, and say which direction each goes.
- [ ] I can use a template reference variable to focus an input.
- [ ] I can bind classes and styles conditionally, including Tailwind classes.
- [ ] I know when to use `[attr.x]` instead of `[x]`, and I add ARIA attributes to icon buttons.
- [ ] I can split a page into a smart page component and presentational UI components.
- [ ] I can name and place files according to the v20+ style guide.
- [ ] I built `NoteCard`, `StatTile` and `PageHeader` for Myspce.
